# ZSTUCA 浙江理工大学计算机协会官网

浙江理工大学计算机协会官网及其相关服务.

此仓库中主要为静态网页的微服务部分以及部署配置文件.

硬件部维修服务的微服务见仓库[ZSTUCA-TEAM/ZSTUCA_HardwareRepair](https://github.com/ZSTUCA-TEAM/ZSTUCA_HardwareRepair).

## 项目文件结构

`/index.html` 网站首页
`/src/assets` 网站资源文件
`/src/view` 各静态子站

## 项目维护方式介绍

由于项目较为古老,目前仅完成从php转化为静态网页的工作.将其转化为Vue项目的工作较为困难,暂未完成,如有兴趣可以自行尝试.

建议新增服务采用微服务架构加上`docker-compose`联排的方式,再用`nginx`管理路由.这样新增服务的后端和前端可以采用自己喜欢的架构,无需由于项目时间跨度受限于古老的架构.

如已习惯现代的前端技术栈,则静态网页不建议随意进行大量修改.每年部署时只需修改qq群的进群链接和招新ppt即可.(在`/index.html`中搜索**维护点**,按照相关注释修改即可).
